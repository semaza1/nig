Ongeza Transaction

Igihe cyifashishwa mu kubika transaction no mu mibare y'inguzanyo.

Expense ishobora kujya kuri system; andi moko asaba user.

Loan Payment: system ibanza kwishyura interest yose ku nguzanyo z'uwo muntu, hanyuma amafaranga asigaye akajya kuri principal.

OUT (withdrawal/expense/other_out) ntirenza amafaranga ari kuri konti wahisemo.

Shyiramo amafaranga yose wishyuye cyangwa usohoye.

Kuri Loan Payment, ushobora kutahitamo loan imwe kuko system ishobora kugabanya amafaranga ku nguzanyo zose z'uwo muntu. Kuri Loan Interest, hitamo loan imwe ushaka kwishyuriraho interest gusa.

Itegeko kuri transaction nshya.
